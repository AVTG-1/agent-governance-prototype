# Reference material (read-only background)

`SPEC.md` is the source of truth. These files explain *why* the spec looks the way it does. Do not build from them directly.

| File | What it is | How to use it |
|---|---|---|
| `proposal-deck.html` | The interactive proposal deck this prototype sits beside (self-contained; open in a browser) | Match its look and vocabulary. The "Prototype" page in the deck is where this demo will be shown or linked. |
| `research/00-meeting-summary.md` | Client discovery notes and internal team views | Context on the client's ask |
| `research/01-deep-research-chatgpt.md` | Unbiased deep research on the client's problem | Strongest source for brownfield and observe-first ideas |
| `research/02-deep-research-claude.md` | Second unbiased deep research | Rogue-agent kinds, detector limits, decision tree by authentication type |
| `research/03-execution-plan-chatgpt.md` | Earlier technical execution plan | Attack chain, request envelope, red-team list |
| `research/04-synthesis-claude-a.md` | Earlier synthesis | Formal checks on AI-drafted policy, before/after "legacy mode" |
| `research/05-synthesis-claude-b.md` | Earlier synthesis | Information barriers, metrics ideas |

Facts in the research about real organisations, regulations or vendors are **not** used in the prototype UI. The prototype is entirely synthetic.
